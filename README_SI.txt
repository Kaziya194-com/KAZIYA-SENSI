KAZIYA FREE FIRE SENSITIVITY AI — SETUP (සිංහල)

1) Node.js install කරගන්න: https://nodejs.org
2) මේ folder එක open කරලා Terminal / Command Prompt එකේ:
   npm install
3) .env.example එක copy කරලා .env කියලා rename කරන්න.
4) .env file එකේ OPENAI_API_KEY= කියන තැනට ඔබේ API key එක දාන්න.
   API key එක කිසිම විටක public HTML/JavaScript එකට දාන්න එපා.
5) Terminal එකේ run කරන්න:
   npm start
6) Browser එකෙන් http://localhost:3000 open කරන්න.

AI KEY එක නැතිනම් website එක local fallback sensitivity values generate කරයි.
Real AI feature එක ක්‍රියාත්මක වීමට valid API key එකක් සහ API usage billing/credits අවශ්‍ය විය හැක.

ONLINE HOSTING:
- Node.js server එක run කළ හැකි hosting එකක් තෝරන්න (උදා: Render, Railway හෝ VPS).
- Project folder එක upload/connect කර build command එක npm install ලෙසත් start command එක npm start ලෙසත් set කරන්න.
- Hosting dashboard එකේ Environment Variables තුළ OPENAI_API_KEY සහ OPENAI_MODEL දාන්න.
- API key එක repository එකට commit කරන්න එපා.
- Static-only hosting (HTML file විතරක් upload කරන සේවාවක්) වලදී backend AI endpoint එක run නොවෙයි.
